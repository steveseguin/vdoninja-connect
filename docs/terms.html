Terms of use

VDO.Ninja Connect is maintained by Steve Seguin. Use the software only with agents, devices and content you own or are authorized to access.

Your connections

You control which clients receive invitations and which content they may send. Treat an invitation as private access to its pairing. Revoke access when a device or client should no longer connect.

Starting an agent request uses the configured Codex account and its applicable limits. Optional audio transcription uses the configured API account. You are responsible for configuring those services and complying with their terms.

Responsible use

Do not use the software for unauthorized access, malicious code execution, deceptive impersonation, harassment or unlawful distribution of content. Do not attempt to bypass another participant's permissions, service quotas or authentication.

Availability and results

Connections depend on your agent computer, network, signaling and model services. Keep the agent computer awake and review model output before relying on it. A queued message is not proof of completed work. After a timeout, check the existing request before sending it again.

The hosted connector applies connection and request limits. Operators may suspend abusive traffic or end access to protect the service. You may stop using the software, revoke connections and remove retained data at any time.
