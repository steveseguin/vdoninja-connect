Try it yourself

  1. Pair the browser using a fresh invitation from your running agent.
  2. Upload a text file with these notes: verify file checksums; document how to revoke a pairing; check reconnect after a restart.
  3. Leave that file checked and ask: “Turn the attached notes into three short checklist items.”
  4. Click Download beside the file to retrieve it. The client verifies its SHA-256 checksum.
  5. Disconnect, reconnect with the saved pairing, then ask: “What were the three checklist items we just discussed?”
