Get help connecting

Agent unavailable

Keep the agent computer awake. Run npm run background -- status, then npm run background -- start if it is stopped. Confirm that the Codex CLI is signed in before requesting a reply.

Invitation already used

Each invitation pairs one client. Generate a new invitation for another browser, phone or hosted connector. Reconnect from a previously paired browser without pasting the old invitation again.

No reply after a timeout

Check the saved request ID. Do not immediately resubmit the same task with a different key. A service restart marks unfinished work interrupted instead of automatically repeating it.

Files or voice

Browser file transfers are limited to 8 MiB; hosted MCP text files are limited to 24 KB. Model attachments support small UTF-8 text files and PNG/JPEG images. Recorded voice requires an OpenAI transcription key on the agent computer. Browser dictation and read-aloud do not require that key.

Report a problem

Open a GitHub issue

Include your operating system, browser, package version and the steps that failed. Do not include full invitation links, keys, tokens, personal documents or private conversation history. Maintainer: Steve Seguin.
